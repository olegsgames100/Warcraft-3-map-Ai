# Последний Круг — широкий загрузочный экран

Текущая иллюстрация: `last-circle-wide.png`, созданная через imagegen на основе
сохранённого исходника `last-circle.png`. Все десять героев находятся слева;
справа оставлено тёмное место для штатного герба и текста Warcraft. Низ свободен
под полосу загрузки. Композиция изначально широкая: герои не вырезаются из 4:3.

В карту импортируется `FullScreen.dds` 1920×1080, несжатый 32-битный RGBA DDS.
При декодировании пиксели точно совпадают с полноцветным исходником, приведённым
к 1920×1080. Палитра 256 цветов и прежнее уменьшение до 512×512 не используются.
Такая текстура предназначена для Reforged 1.32+, включая установленный клиент
2.0.4. Секторная упаковка MPQ сохранена, SINGLE_UNIT не используется.

Модель `LoadingScreen-wide-template.mdx` взята из примера для широкого экрана
Reforged: [статья Roy Mustang](https://xgm.guru/p/wc3/loadingscreenrefroged),
[исходный архив](https://xgm.guru/files/100/247472/LoadingScreen.zip).
Путь текстуры в модели заменяется на FullScreen.dds при генерации.
Поддержка DDS описана автором [High Resolution Loading Screens](https://www.hiveworkshop.com/threads/high-resolution-loading-screens.322172/).

`lore.json` содержит короткие строки для правой области нативного интерфейса.
Лор не впечатывается в иллюстрацию. `tools/set_loading_screen.py` обновляет DDS,
модель, список импорта и загрузочные поля W3I, сохраняя игровые данные.
Нужен Pillow только для преобразования изображения. Обычная сборка использует
готовые ресурсы. Старые исходники хранятся для восстановления, но не импортируются.


Актуальное исправление чёрного фона: DDS полностью исключён из карты.
Режим wide-blp использует ArenaWide_v3.blp (BLP1 1920×1080, палитра 256
цветов, 11 mip-уровней) и ArenaWide_v3.mdx с соответствующим путём текстуры.
Увеличенный размер сохраняет детализацию; палитра означает, что это уже не
полноцветный lossless DDS из предыдущего описания. Имена изменены для исключения
повторного использования прежних ресурсов. Исходные PNG сохранены без изменений.

Резервный режим: `python tools/set_loading_screen.py --mode standard`.
Он включает штатный фон с индексом 0, очищает путь пользовательской модели,
убирает все загрузочные импорты из архива и сохраняет лор. Pillow этому режиму
не нужен. Основной режим: `--mode wide-blp`, затем обычная сборка карты.
