# Hero Arena

Готовая карта: `Hero_Arena_126a.w3x`. Текущая версия использует Lua и требует
Warcraft III 1.31+ / Reforged. Суффикс `126a` в имени файла сохранён из исходного
проекта; текущий скрипт не совместим с клиентом 1.26a.

## Сборка

Для повторного применения настроек внешнего вида и кнопок:

```powershell
python tools/set_hero_models.py
python tools/set_ability_ui.py
python tools/set_gameplay_objects.py
python tools/set_landscape.py
python tools/set_items.py
python tools/set_multiplayer.py
```

```powershell
python tools/build_map.py
```

Нужен Python 3.9+. Дополнительные библиотеки для сборки не нужны. Скрипт собирает
архив из файлов, перечисленных в `(listfile)`, и заменяет готовую карту только
после формирования архива. Внутрь попадают актуальные `war3map.lua`, метаданные
с включённым Lua и данные объектов. Старый JASS-скрипт и устаревшие контрольные
суммы `(attributes)` не упаковываются.

## Проверка

```powershell
python -m pip install lupa mpyq
python tools/check_map.py
```

Проверка читает собранный MPQ сторонней библиотекой, сравнивает все 23 файла
с исходниками и выполняет Lua 5.3 в тестовом окружении: инициализация при 1 и 4
игроках, выбор всех 10 героев через диалог/чат, ошибочный и повторный выбор,
отказ создания героя, первая волна и сборка предмета. Это проверка скрипта
с имитацией функций Warcraft III; запуск в самом игровом клиенте проверяется
отдельно.

Свежая игровая сборка: `Hero_Arena_Landscape_Balance.w3x`. Спокойная поляна с
дорожками и лесом по краям. Ультимейты открываются на 5-м уровне; опыт от
нейтральных противников сохраняется вплоть до максимального 30-го уровня.
Обычный интервал волн — 45 секунд, после зачистки — 7 секунд.

При редактировании источником скрипта служит `war3map.lua`. Файлы GUI-триггеров
`war3map.wtg`/`war3map.wct` унаследованы от прежней версии и не являются
источником текущего скрипта арены; после изменений используйте команду сборки.

Описание поля языка скрипта: [реализация MapInfo в War3Net](https://github.com/Drake53/War3Net/blob/master/src/War3Net.Build.Core/Serialization/Binary/Info/MapInfo.cs).
Формат архива: [StormLib](https://github.com/ladislav-zezula/StormLib).


Магазины: слева внизу от центра — расходники, справа — компоненты.
Банки здоровья/маны стоят по 400 золота; свиток лечения — 650, защиты — 600,
мазь — 450. Запас расходников — 3, пополнение раз в минуту. Все 9 рецептов
из UPDATES.md собираются автоматически; справка есть в F9. Компонент
«Амулет Маны» имеет отдельный ID I0MA, обычная банка pman в рецептах не нужна.
Последняя сборка с магазинами: Hero_Arena_Shops.w3x.


Совместная игра: `Hero_Arena_Coop.w3x`, 1–4 человека в одной команде, включая
режим на двоих. Неиспользуемые слоты можно оставить пустыми. Первая волна
начинается через 15 секунд после того, как все подключённые игроки выбрали
героев. Каждый управляет своим героем; обзор общий. Настройки лобби и
команды синхронизирует `tools/set_multiplayer.py`.


Загрузочный экран: `Hero_Arena_Last_Circle.w3x`. Сгенерированная иллюстрация со
всеми десятью героями и русский лор «Последний Круг». Источники находятся в
`assets/loading/`, текст — в `assets/loading/lore.json`. Для изменения фона или
лора запустите `python tools/set_loading_screen.py` в окружении с Pillow, затем
обычную сборку. В архив входят `LoadingScreen.mdx`, `FullScreen.blp` и список
импорта; PNG-оригинал остаётся в проекте. Для обычной сборки Pillow не нужен.


Исправленная сборка загрузочного экрана: `Hero_Arena_Last_Circle_Fixed.w3x`.
Все файлы используют совместимую с W3X секторную упаковку; текстура фона —
палитровый BLP1 512×512. Тест упаковки: `python tests/test_mpq_layout.py`.


Актуальная широкоформатная сборка: `Hero_Arena_Widescreen_HD.w3x`.
Экран переделан под 16:9: полноцветный DDS 1920×1080, герои слева и отдельная
тёмная область справа для штатного герба и короткого лора. Эта версия загрузки
требует Reforged 1.32+ (включая клиент 2.0.4); Lua-скрипт остаётся прежним.


После сообщения о чёрном фоне DDS отключён. Используйте
`Hero_Arena_Loading_BLP.w3x` (широкий BLP 1920×1080) или
`Hero_Arena_Stock_Loading.w3x` (штатный экран без импортированной графики).
Оба варианта сохраняют игровой контент и лор. Выбор режима воспроизводится
через `tools/set_loading_screen.py --mode wide-blp` / `--mode standard`.


Обновление Мастера: `Hero_Arena_Samurai.w3x` (широкий BLP-фон) и
`Hero_Arena_Samurai_Stock.w3x` (штатный экран). E длится 2–6 секунд; новый W
«Метка Иай» наносит отложенный разрез и снижает броню. Полная выдержка E
усиливает его урон. Q и ультимейт сохранены.
